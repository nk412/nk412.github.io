# Greenland

::dek(What is it about lands without trees that keeps calling?)

::bleed:qoornoq.avif(Like litter on a polished floor. Icebergs at Qoornoq.)

In the 1970s, the Danish government decided that it was too expensive to run little settlements, and so forced everyone out to the bigger towns. Today, Qoornoq is officially an abandoned settlement, which means no new houses can be built, and the old ones have become summer homes.
